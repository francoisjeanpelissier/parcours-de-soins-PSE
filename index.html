🧭 Les 4 grandes étapes

👨‍⚕️
1. Médecin traitant Le patient choisit et déclare un médecin traitant.
📋
2. Évaluation Le médecin évalue la situation.
🩺
3. Spécialiste Si nécessaire, le médecin oriente vers un spécialiste.
🔄
4. Suivi coordonné Les soins sont organisés autour du patient.

📖 Règles du jeu

  1. Chaque joueur choisit son nom.
  2. Le premier joueur est désigné.
  3. Il doit obligatoirement lancer le dé.
  4. Son pion avance automatiquement.
  5. Une carte QCM apparaît automatiquement.
  6. Le joueur choisit une réponse parmi les quatre propositions.
  7. Le site indique immédiatement si la réponse est correcte.
  8. Une explication apparaît après la réponse.
  9. Une fois le QCM terminé, le joueur peut terminer son tour.
  10. Le joueur suivant prend alors la main.

🏥 Objectif pédagogique

Comprendre le principe du parcours de soins coordonné : médecin traitant, évaluation, orientation vers un spécialiste si nécessaire et suivi coordonné.
